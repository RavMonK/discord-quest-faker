# เริ่มต้นใช้งาน

## 1. ความต้องการ

| สิ่งที่ต้องมี | หมายเหตุ |
|---|---|
| **Node.js 18 ขึ้นไป** | ดาวน์โหลดจาก <https://nodejs.org> (macOS: `brew install node`) |
| **Discord เวอร์ชัน desktop** | เปิดค้างไว้ตลอดที่รันเกมปลอม — เวอร์ชันเว็บตรวจจับโปรเซสไม่ได้เลย |
| **.NET Framework** (Windows) | เพื่อให้มี `csc.exe` — Windows ส่วนใหญ่มีมาให้แล้ว ถ้าไม่มีโปรแกรมจะถอยไปใช้ชั้นสำรองที่**ไม่มีหน้าต่าง** และมีโอกาสตรวจไม่เจอ |

**ไม่ต้อง `npm install`** โปรเจกต์นี้ไม่มี dependency ภายนอกเลยแม้แต่ตัวเดียว

เช็คว่า Node ใช้ได้:

```bash
node --version
```

## 2. ตั้งค่า Discord ให้ยอมตรวจจับเกม

ต้องเปิดสองอย่างนี้ในตัว Discord desktop ไม่งั้นโปรเซสปลอมจะรันเปล่า ๆ:

1. **User Settings → Activity Privacy →** เปิด *"Share your detected activities with others"*
2. **User Settings → Registered Games →** เปิด *"Display currently running game as a status message"*

## 3. รันโปรแกรม

### Windows

ดับเบิลคลิก `start.bat` หรือรันในเทอร์มินัล:

```bash
node src/index.js
```

### macOS / Linux

```bash
chmod +x start.sh && ./start.sh
```

โปรแกรมจะ:

1. โหลดรายชื่อเกมจากไฟล์ cache ขึ้นมาก่อน (ใช้งานได้ทันที ไม่ต้องรอเน็ต)
2. **ดึงลิสต์ใหม่จาก Discord แบบ background** แล้วเขียนทับ `data/games.json` (~10,400 เกม)
3. เปิดหน้าเว็บควบคุมที่ <http://127.0.0.1:5011> ให้อัตโนมัติ

ถ้าพอร์ตชนกับอะไรอยู่ โปรแกรมจะบอกว่าโปรเซสไหนถืออยู่ (ชื่อ + pid) แล้วถามว่าจะ kill ทิ้งไหม
ตอบ `y` เพื่อยึดพอร์ต หรือ `n` แล้วเปลี่ยนพอร์ตด้วย `--port 8080`

## 4. รันเกมปลอมครั้งแรก

ในหน้าเว็บ:

1. พิมพ์ชื่อเกมในช่องค้นหา (ลิสต์โหลดเพิ่มเองเมื่อเลื่อนลง ไม่พิมพ์ก็ไล่ดูครบทั้งหมื่นเกมได้)
2. (ไม่บังคับ) ตั้ง **Auto-stop after ... min** ถ้าอยากให้หยุดเอง
3. กด **Start**

จะมี **หน้าต่างเล็ก ๆ ชื่อเกมนั้นเด้งขึ้นมา** — นั่นคือโปรเซสปลอมที่ Discord ต้องเห็น

<p align="center">
  <img src="https://raw.githubusercontent.com/RavMonK/discord-quest-faker/main/docs/screenshots/placeholder-window.png" alt="หน้าต่างโปรเซสปลอมของ Overwatch" width="440">
</p>

ในหน้าต่างนั้นมี **รูปเกม**, ชื่อไฟล์ที่กำลังปลอมเป็น, **เวลาที่เดินมาแล้ว** (นับทุกวินาที)
และบรรทัด **Auto-stop** ที่บอกว่าเหลืออีกกี่นาที (ถ้าไม่ได้ตั้งจะขึ้น `off`)

> ⚠️ **อย่าปิดหน้าต่างนั้น** — ปิดหน้าต่าง = หยุดเกมนั้น เหมือนกดปุ่ม Stop ในหน้าเว็บ
> โปรแกรมจะไม่เปิดขึ้นมาใหม่ให้

ภายในไม่กี่วินาที Discord ควรขึ้นว่าคุณกำลังเล่นเกมนั้น ถ้าไม่ขึ้น ไปที่
[แก้ปัญหา & FAQ](TH-Troubleshooting)

## 5. หยุด

- กด **Stop** ในหน้าเว็บ (หรือ **Stop all** ถ้ารันหลายตัว)
- หรือปิดหน้าต่างโปรเซสปลอม
- หรือกด **Ctrl+C** ที่เทอร์มินัล — ปิดโปรแกรมแล้วโปรเซสปลอมทุกตัวจะถูกปิดตามให้อัตโนมัติ

## ทางเลือก: ไม่ใช้หน้าเว็บ

รันตรงจาก command line ได้เลย:

```bash
node src/index.js --start "Overwatch" --duration 60
```

ดูคำสั่งทั้งหมดที่ [คำสั่ง command line](TH-CLI-Reference)
